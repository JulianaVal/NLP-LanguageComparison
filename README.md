# NLP-LanguageComparison
For this project objective is to determine wheter the classification algorithm works similarly in the original review against the translated in english version, since many websites translate reviews.
The datasets are reviews in Spanish, Protuguese and Basque with its translated columns and sentiment classification. Additionally one English only dataset is used to train a model which will be applied to the translated version to compare results.

'PT-EN Zomato cleaned.csv' is the dataset Portuguese excluding personal details of customers uploaded to github for ethical reasons. 
'reviews.csv' is the dataset with all the Basque reviews merged into one file.
Skip the cells where the original data is pre-processed since those files are not available to access.
